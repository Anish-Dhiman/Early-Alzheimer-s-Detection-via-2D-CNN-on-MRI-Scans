1. START THE SERVER:
   cd /vercel/share/v0-project
   npm install              (first time only)
   npm start

2. OPEN IN BROWSER:
   http://localhost:5000

3. TEST THE API:
   # Health check
   curl http://localhost:5000/api/health
   
   # Prediction
   curl -X POST -F "file=@image.png" http://localhost:5000/api/predict
   
   # Model info
   curl http://localhost:5000/api/model-info

4. DEPLOY TO PRODUCTION:
   • Docker: docker build -t app . && docker run -p 5000:5000 app
   • PM2: pm2 start server.js --name "alzheimers"
   • Vercel: vercel --prod

Solution: This is DEMO MODE - add a real model to enable production mode

Problem: Images not uploading
Solution: Check file size (<50MB), format (PNG/JPG/TIFF), and browser logs

Problem: Server crashes on startup
Solution: Check Node.js version (18+), read error message, check file permissions
