Project Overview

This project presents an end-to-end solution for early detection of Alzheimer's disease using 2D Convolutional Neural Networks (CNN) on MRI scan images. The system is designed to assist healthcare professionals in identifying different stages of Alzheimer's disease through automated analysis of brain imaging.

Problem Statement

Alzheimer's disease is a progressive neurodegenerative disorder that affects millions worldwide. Early detection is crucial for:

  • Timely intervention and treatment planning
  • Slowing disease progression through early medication
  • Improving quality of life for patients and caregivers
  • Reducing healthcare costs through preventive care

Our Solution

We developed a deep learning-based system that:

  • Automatically analyzes MRI scans for Alzheimer's markers
  • Classifies patients into 4 stages of cognitive decline
  • Provides visual explanations using Grad-CAM
  • Offers confidence scores for clinical decision support

System Pipeline

1. Data Preprocessing

MRI scans are resized to 224x224 pixels and normalized. Data augmentation (rotation, flip, zoom) is applied to increase dataset diversity and prevent overfitting.

2. CNN Feature Extraction

A custom 2D CNN with 4 convolutional blocks extracts hierarchical features from brain images, detecting patterns from simple edges to complex anatomical structures.

3. Classification

Fully connected layers process extracted features to classify the MRI into one of four categories: Non-Demented, Very Mild, Mild, or Moderate Demented.

4. Explainability (Grad-CAM)

Gradient-weighted Class Activation Mapping highlights brain regions that influenced the prediction, providing transparency for clinical validation.

Key Features

  • Batch Normalization for training stability
  • Dropout layers to prevent overfitting
  • L2 Regularization for weight decay
  • Global Average Pooling to reduce parameters
  • Softmax output for multi-class classification

Classification Classes

Class Description Clinical Significance
Non-Demented Normal brain structure, no signs of cognitive decline Baseline for healthy aging
Very Mild Demented Early signs, subtle memory issues, minimal atrophy Preclinical stage, monitoring needed
Mild Demented Noticeable impairment, hippocampal atrophy visible Early intervention recommended
Moderate Demented Significant decline, widespread cortical atrophy Requires active management
